

# excel-sales-distribution_practice
Interactive Excel dashboard to analyze sales data using Pivot Tables and charts

A dynamic Excel dashboard built to analyze and visualize retail sales data.  
The project showcases data transformation, pivot table usage, and advanced dashboard design.

## 🔍 Overview

This project includes:
- Cleaned sales data by branch, product category, and month
- Key KPIs: Total Sales, Number of Invoices, Inventory
- Visual charts: Column charts, donut charts, slicers
- Interactive dashboard built using PivotTables and Excel formulas

## 📁 File Structure

- `SalesDashboard.xlsx`: The main file with raw data, analysis, and the dashboard.

## 🎯 Purpose

Designed for:
- Practicing data analysis using Excel
- Creating visually appealing and interactive dashboards
- Presenting business insights from raw data

## 🛠️ Tools Used

- Microsoft Excel
  - Pivot Tables
  - Charts
  - Conditional Formatting
  - Dashboard Design
